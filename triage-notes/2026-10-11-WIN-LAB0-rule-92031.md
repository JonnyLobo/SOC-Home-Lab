## Scope

This note covers only the alerts from rule 92031. The concurrent alerts 92205, 92066 and 92021 are handled in separate tickets.

## Summary

The Wazuh agent ran `net user` when its service restarted. The rule flagged it as local account discovery. The activity is legitimate.

## Evidence

### Process tree

```
wazuh-agent.exe  (C:\Program Files (x86)\ossec-agent\)
└── net.exe "net user"
    └── net1.exe "C:\Windows\system32\net1 user"
```

### Key fields

| Field | Value |
|---|---|
| `image` | `C:\Windows\SysWOW64\net.exe` |
| `commandLine` | `net user` |
| `parentImage` | `C:\Program Files (x86)\ossec-agent\wazuh-agent.exe` |
| `parentCommandLine` | `"C:\Program Files (x86)\ossec-agent\wazuh-agent.exe"` |

### Checks

- The parent process path matches the agent's installation directory.
- The agent was installed from an `.msi` with a valid digital signature from Wazuh, Inc.
- The event happened right after the agent service was restarted (`Restart-Service WazuhSvc`).

## Analysis

`net user` lists local accounts, a typical discovery technique (T1087.001). In this case the parent process is the Wazuh agent, and the behavior is consistent with its audit and inventory modules, which collect system information at startup.

## Verdict

**False positive:** benign activity generated by the monitoring tool itself.

## Actions and recommendations

1. Close the rule 92031 alerts for this event.
2. **Proposed tuning (not applied):** exclude from rule 92031 the processes whose `parentImage` is exactly `wazuh-agent.exe` in its installation path. Validate with `wazuh-logtest` before applying.
3. **Tuning risk:** malware posing as `wazuh-agent.exe` in that same path would be excluded. **Mitigation:** the exclusion requires the full path, and writing to that folder requires administrator privileges.

## Follow-up

- Closed: there was an open concern about software installed from an unverified source on this endpoint. Instead of investigating it, the endpoint was rebuilt from scratch (now WIN-LAB1). This note does not depend on that decision.
